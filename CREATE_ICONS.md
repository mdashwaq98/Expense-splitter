# How to Create App Icons

Since I can't create actual image files, you'll need to create two icon files:

## Required Files:
- `static/icon-192.png` (192x192 pixels)
- `static/icon-512.png` (512x512 pixels)

## Quick Ways to Create Icons:

### Option 1: Use an Online Icon Generator (Easiest)
1. Go to: https://www.favicon-generator.org/ or https://realfavicongenerator.net/
2. Upload any image or use text "ES" or "💰"
3. Download the generated icons
4. Rename them to `icon-192.png` and `icon-512.png`
5. Place in the `static/` folder

### Option 2: Use Canva (Free)
1. Go to https://www.canva.com/
2. Create custom size: 512x512 pixels
3. Design your icon:
   - Dark background (#1a1f2e)
   - Add icon/emoji 💰 or text "ES"
   - Use gradient colors (#5b7cff)
4. Download as PNG
5. Resize to 192x192 for the smaller version
6. Save both in `static/` folder

### Option 3: Use Paint/Photo Editor
1. Create 512x512 image
2. Fill with dark color
3. Add "ES" text or $ symbol in center
4. Save as `icon-512.png`
5. Resize to 192x192 and save as `icon-192.png`

### Option 4: Simple Placeholder (Temporary)
Until you create proper icons, the app will still work, but won't have custom icons when installed.

## Icon Design Tips:
- Use dark background to match app theme
- Simple, recognizable symbol
- High contrast
- No text smaller than 30px
- Centered design

The icons are used when users install the app on their phone's home screen!
