# Quick Start Guide

## 🚀 Getting Started in 3 Steps

### Step 1: Install Dependencies
```bash
npm install
```

### Step 2: Start the App
```bash
npm start
```

### Step 3: Run on Your Device
- **For iOS Simulator**: Press `i`
- **For Android Emulator**: Press `a`  
- **For Physical Device**: Scan the QR code with Expo Go app

## 📱 First Time Using the App

1. **Create an Account**
   - Tap "Don't have an account? Sign up"
   - Enter your name, email, and password (min 6 characters)
   - Tap "Sign Up"

2. **Add Your First Expense**
   - You'll land on the Expenses tab
   - Tap the blue "+" button at the bottom right
   - Enter a description (e.g., "Lunch")
   - Enter an amount (e.g., "25.50")
   - Tap "Add"

3. **Create a Group**
   - Go to the "Groups" tab at the bottom
   - Tap the green "+" button
   - Enter a group name (e.g., "Roommates")
   - Tap "Create"

4. **View Your Profile**
   - Go to the "Profile" tab at the bottom
   - See your statistics and overall balance
   - Edit your profile if needed

## ✨ Key Features

- **Expenses Tab** (💰): Track all your expenses
- **Groups Tab** (👥): Organize expenses by groups
- **Profile Tab** (👤): Manage your account and view stats

## 🎨 App Navigation

```
├─ Login/Signup (Authentication)
│
└─ Main App (Bottom Tabs)
   ├─ 💰 Expenses - Add, view, delete expenses
   ├─ 👥 Groups - Create and manage groups
   └─ 👤 Profile - Account settings and statistics
```

## 💡 Tips

- **Long-press** on any expense or group to delete it
- Expenses can be assigned to groups for better organization
- Your balance shows if you're owed money (green) or owe money (red)
- All data is saved locally on your device

## 🐛 Troubleshooting

**App won't open?**
- Make sure you ran `npm install` first
- Try: `expo start -c` to clear cache

**Can't login?**
- Make sure you've created an account first
- Password must be at least 6 characters

**Need help?**
- Check the main README.md for detailed documentation
- Make sure all dependencies are installed correctly
